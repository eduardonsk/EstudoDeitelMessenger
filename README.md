# Estudo de caso Deitel Messenger

O trabalho investiga o que acontece quando um produtor e um consumidor acessam um único valor compartilhado. As três execuções do grupo, a comparação com os slides de Deitel e a fundamentação em Sistemas Operacionais estão no [relatório em PDF](sistemas-operacionais-deitel/relatorio.pdf).

Para compilar os exemplos e conferir as saídas, consulte o [roteiro de execução](sistemas-operacionais-deitel/README.md).
